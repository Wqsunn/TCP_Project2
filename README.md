# Практическая работа №2: Программный маршрутизатор и многоклиентская сеть
## Структура проекта
- `router.py` — главный файл маршрутизатора (слушает TCP порт 5000 и UDP порт 6000).
- `client_tcp.py` — TCP-клиент (для подсети 1).
- `client_udp.py` — UDP-клиент (для подсети 2).
- `clients.json` — таблица клиентов (IP, подсеть, протокол, приоритет).
## Как запустить
1. python router.py
2. Поочередно запускаем клиентов python client_tcp.py (меняем NAME перед каждым запуском)
3. Поочередно запускаем клиентов python client_udp.py (меняем NAME перед каждым запуском)
